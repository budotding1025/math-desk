## U3 三位数乘两位数（已有第 1–2 页）

### 一、填空（摘录）

1. 23 个 12 的和＝**276**；17 个 26 的积＝**442**
2. 最大两位数×最小三位数＝99×100＝**9900**
3. 457＋(　)＝9×82 → 9×82＝738 → 空＝**281**
4. 一天轨道圈数：24 小时＝1440 分，1440÷90＝**16** 圈
5. 12345×9－5＝**111105**；123456789×9－1＝**1111111100**  
   （规律：乘数位数个 1，再往后补 0 的模式——按卷面递推核对）
6. 12×14 正确方法：东东 ✓（12 个 14）；思思 ✓（14×6＋14×6）；乐乐 ✓（12×10＋12×4）；成成 ✗
7. 长＋1 面积＋16 → 宽＝16；宽＋1 面积＋25 → 长＝25；面积＝**400**

### 二、选一选（摘录）

1. 箭头所指部分积＝114×10 → **④**（10 圈共 1140 分）或卷面选项「1140 分 / 10 圈」
2. 误输入 ×20，要变成 ×120 → 再 **×6** → **③**
3. 「够用」估算宜偏大：思思 300×32≈9600 → **③**（按卷面四人算法）

### 题型 / 重难点（供补第 3–4 页时对标）

| 类型 | 重难点 |
| --- | --- |
| 积的变化规律 | 一个因数不变，另一个×几积×几 |
| 估算 | 进一法 / 四舍五入，看问题要「够不够」 |
| 竖式意义 | 部分积表示「多少个几十」 |
| 速度问题 | 路程＝速度×时间 |
| 面积增减 | 长/宽各加 1 与原宽/长的关系 |

## U4 数量关系（已有第 1–2 页）

### 一、填空（摘录）

1. 下午 **621** 人；数量关系：**总数－部分＝另一部分**（1280－659＝621）
2. 一共 **1620** 元；**单价×数量＝总价**（108×15）
3. 已行 274－34＝240 千米；速度 **80** 千米/时（240÷3）
4. 女生 113＋46＝159；共 **272** 人
5. （1）贵 → **单价**高；（2）已知单价、数量，求总价；（3）总价＝单价×数量
6. 用时 6 小时，速度 1260÷6＝210 → 最接近 **高铁**（230）
7. 箭头部分积：表示 **20** 件毛衣，**2500** 元（125×20）

### 二、选一选（摘录）

1. 15 分钟行驶路程 → 求 **② 路程**
2. 400 元买 10 个 → 求 **① 单价**
3. 比最快：把单位统一后再比（常见答案为民航或高铁，**按选项单位换算**）
4. 竖式第二行部分积 → **③ 10 分钟路程**
5. 不能用 15×4 解决的：**④**（降价前后单价混用）或「求面积却只乘一边」类——按卷面选项

### 题型 / 重难点

- 三种数量关系：总价＝单价×数量；路程＝速度×时间；总数＝部分＋部分  
- 竖式里「错一位」表示×10  
- 单位换算后再比较快慢

## U5 平行四边形和梯形（已有第 1–2 页）

### 一、填空（摘录）

1. 互相垂直 / 互相平行：按图①–⑤判断（平行两组、垂直两组、相交一组——**以实图为准**）
2. 梯形标 ○、平行四边形标 △（长方形、正方形也算平行四边形；菱形同）
3. 从线外一点到直线：**垂**线段最短；长度叫点到直线的 **距离**
4. 只有一组对边平行的四边形叫 **梯形**；平行的两边叫 **上底、下底**；不平行的叫 **腰**
5. 最多 **2** 个直角 → **直角**梯形
6. 等腰梯形两腰 **相等**，同一底上的两个底角 **相等**
7. 周长＝(15＋18)×2＝**66** cm
8. a∥b，d⊥a 且 d⊥b 等：按图写垂直、平行的直线

### 二、选一选 / 解决问题

- 被遮挡图形「不可能是」：看露出的两边是否平行——**按实图**
- 等腰梯形一刀切：不能切成两块完全相同的 **长方形**（常见）
- 两组对边分别平行 → **平行四边形**
- 作图：过点作垂线；两垂线互相 **平行**

### 题型 / 重难点

| 类型 | 重难点 |
| --- | --- |
| 平行与垂直 | 用三角板推平行；垂线唯一 |
| 梯形 vs 平行四边形 | 一组平行 vs 两组平行 |
| 正方形/长方形 | 特殊的平行四边形 |
| 作图 | 过点作垂线、平行线 |
