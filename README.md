# 数学书桌 / Math Desk

考前「查漏 + 计算提速」可打印练习。与 English Desk、Chinese Desk 一套命名。  
**主色：天蓝色**。  
**状态：已上线（GitHub Pages）**

**打开：https://budotding1025.github.io/math-desk/**  
仓库：https://github.com/budotding1025/math-desk  

## 打开

- **线上**：https://budotding1025.github.io/math-desk/
- **本地**：双击 `打开数学书桌.bat`，或 `python desk_server.py` → http://127.0.0.1:8733/

框架与语文书桌一致：

| 页 | 内容 |
| --- | --- |
| **主页** | 当前进度（默认：第二单元 · 第一课「日常练习」） |
| **路径** | 每单元：日常练习·组卷打印、考前测试 |
| **记录** | 错题库（登记 + 各单元重练纸） |

## 日常练习 · 组卷打印

在首页勾选 **①计算 / ②重难点 / ③应用题**（一项或多项）→ **生成 A4** → **打印 / 另存 PDF**。

- **合订一张**：多项排在同一张 A4，合计约 15 分钟  
- **分项分页**：每项一页 A4，各约 15 分钟  

## 时长（固定）

| 类型 | 时长 |
| --- | --- |
| **日常练习**（①计算 / ②重难点 / ③应用题，分开出纸） | **每次约 15 分钟** |
| **考前测试**（④原卷 / 延展卷） | **固定 30–40 分钟** |

⑤错题库按错题量订正。题型对照教材 PDF + 单元卷 JPG。详见 `units/_五条线说明.md`。

## 每单元五条线

| # | 线 | 归类 | 做什么 |
| --- | --- | --- | --- |
| 1 | 日常计算练习 | 日常 · 约 15 分钟 | 口算/基础计算提速，少量竖式 |
| 2 | 重难点题型练习 | 日常 · 约 15 分钟 | 教材+试卷易错点、概念与典型题 |
| 3 | 应用题练习 | 日常 · 约 15 分钟 | 短应用/情境；与口算分开出纸 |
| 4 | 考前测试 | 测前 · 30–40 分钟 | 上传原卷 → 高清入库 → 延展难度与题型 |
| 5 | 错题库 | 订正 | 计算错 / 概念错分栏重练 |

## 怎么用

1. **日常**：选 ① / ② / ③ 任一张，番茄钟约 **15 分钟** 做完。  
2. **测前**：④ 考前测试 **30–40 分钟**；错题进 ⑤。  
3. 延展卷放进 `04-考前测试/extended/`。
